🔴 Red-Team Tactical Portfolio — Abdul Ahad
Welcome to the source repository for my personal cybersecurity portfolio. Built with a dark tactical/red-team aesthetic, this single-page site highlights my journey as a Software Engineering student specializing in penetration testing, web security, log analysis, and offensive operations.

⚡ Key Features
Red-Ops Tactical Visual Theme: Custom dark-mode UI with animated CRT scanlines, a grid scanning radar effect, glowing HUD borders, and blinking terminal cursors.

Mission Logs & Case Studies: Interactive dialog modals breaking down hands-on lab investigations (Hack The Box, Sherlocks, Web Security, and Active Directory).

Attack Surface & Skill Matrix: Categorized technical competencies spanning Reconnaissance, Web Exploitation, System/Linux Security, and Enterprise Controls.

Cyber Range Record: Highlighting competitive achievements including the NUST DigiInn Cyber Range CTF and Black Hat MEA qualifications.

Zero Dependencies: Pure HTML5, CSS3, and vanilla JavaScript—fast loading with zero external npm dependencies or heavy frameworks.

🛠️ Tech Stack
Markup: HTML5 (Semantic tags, native <dialog> elements)

Styling: CSS3 (CSS Variables, Flexbox, CSS Grid, Custom Keyframe Animations)

Scripting: Vanilla JavaScript (ES6+ DOM manipulation)

Typography: Inter & JetBrains Mono (Google Fonts)

🚀 Quick Start & Deployment
Local Setup
1. Clone the repository:
git clone https://github.com/your-username/red-team-portfolio.git

2. Navigate into the project folder:
 cd red-team-portfolio

3. Open index.html directly in your web browser or run it with a local server like VS Code's Live Server extension.

Hosting on GitHub Pages
Go to your repository Settings on GitHub.

Select Pages from the left navigation sidebar under Code and automation.

Under Build and deployment, select Deploy from a branch.

Set the branch to main (or master) / /root and click Save.

Your live portfolio link will generate automatically within 1–2 minutes.
